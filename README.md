# Борт «Добрых снов»

Одностраничный сайт вымышленной компании.

**Автор:** Абеленцев Марк Артурович, РИЦП 251, 2 курс.

Проект выполнен в рамках 1-го модуля 1-го курса.

## О проекте

Борт «Добрых снов» — вымышленная компания, которая доставляет пассажиров в места из их снов, даже в несуществующие. Город на изнанке неба, остров из детской мечты, страна, которой нет ни на одной карте, — достаточно уснуть, а остальное экипаж возьмёт на себя. Ведь у грёз и путешествий нет предела.

Главная деталь сайта анимация на пятом div-е. При прокрутке он останавливается, и вместо движения по странице проигрывается анимация: глаз на звезде закрывается, звезда становится жёлтой, небо и самолёт меняют цвет, и мир словно переворачивается. Анимация привязана к прокрутке и работает в обе стороны.

## Стек

- **HTML5** — разметка страницы.
- **CSS3** — пользовательские свойства, `calc()`, контейнерные единицы `cqw` для масштабирования макета шириной 1920 px под любой экран, `position: sticky`, `@font-face`.
- **JavaScript** без библиотек — анимация пятого экрана: прогресс прокрутки, `requestAnimationFrame`, морфинг SVG-путей век, плавная смена цветов.
- **SVG** — иллюстрации, экспортированные из Figma.
- **Figma** — макет.
- Шрифт **Anglecia Pro Display** (обычное начертание и курсив).

Проект сделан с использованием нейросети **Claude Opus 5.5**.

## Структура

```
index.html           страница
styles/style.css     точка входа стилей
styles/reset.css     сброс стилей браузера
styles/fonts.css     подключение шрифтов
styles/main.css      базовые переменные и секции
styles/sections/     стили экранов div1–div8
scripts/flip.js      анимация пятого экрана
assets/fonts/        шрифты
assets/images/       SVG-иллюстрации по экранам
```

## Запуск

Открыть `index.html` в браузере. Сервер и сборка не нужны.
